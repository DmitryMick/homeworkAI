# Homework AI Projects

This repository contains various projects developed as part of the homework assignments.

## Project Structure

### SQL Analysis
A collection of SQL queries for analyzing sales data, including customer spending patterns and monthly sales trends.
- Located in `SQLqueries/` directory
- Uses SQLite for data analysis
- Includes sample data and analysis queries

### Calculator
A web-based monthly expenses calculator application that helps users track and analyze their spending patterns.
- Features expense tracking and total calculations
- Built with HTML, CSS, and JavaScript
- Located in the `calculator/` directory

### API Testing
A directory for API testing tasks and examples.
- Contains test cases and documentation
- Located in the `APItest/` directory

## Getting Started

Each project directory contains its own README with specific instructions for setup and usage.
