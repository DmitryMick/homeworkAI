# SQL Analysis Queries

This directory contains SQL queries for analyzing sales data. You can run these queries directly in [SQLite Online](https://sqliteonline.com/).

## Query Files

1. [01_init_database.sql](https://sqliteonline.com/#fiddle=init_database)
   - Creates the orders table
   - Inserts sample data for analysis

2. [02_march_sales.sql](https://sqliteonline.com/#fiddle=march_sales)
   - Calculates total sales volume for March 2024
   - Expected result: 27,000

3. [03_top_customer.sql](https://sqliteonline.com/#fiddle=top_customer)
   - Finds the customer who spent the most overall
   - Expected result: Alice with 20,000

4. [04_avg_order_value.sql](https://sqliteonline.com/#fiddle=avg_order_value)
   - Calculates average order value for the last three months
   - Expected result: 6,000

## How to Use

1. Click on any query link above to open it in SQLite Online
2. Copy the contents of `01_init_database.sql` and run it first
3. Then run any of the analysis queries to see the results

Note: The links above are examples and need to be replaced with actual SQLite Online fiddle links once the queries are saved there.
